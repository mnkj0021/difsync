Install or repair DifSync

On demand

Already paired? Run this command on Windows to install or repair the local DifSync dashboard. Opening the app makes the PC reachable. Closing it takes the PC offline.

powershell -NoProfile -ExecutionPolicy Bypass -Command "iwr 'https://difsync.com/install/windows.ps1' -UseBasicParsing -OutFile '$env:TEMP\difsync-install.ps1'; & '$env:TEMP\difsync-install.ps1'"
